## 📖 Giới thiệu

**ST VLUTE** là ứng dụng **Expo / React Native** giúp sinh viên VLUTE xem nhanh:

- Thời khóa biểu
- Điểm số & điểm thành phần
- Hồ sơ học tập
- Lịch học theo ngày

Ứng dụng đăng nhập bằng tài khoản **cổng đào tạo VLUTE** — không cần đăng ký tài khoản riêng. Hoạt động độc lập, lấy dữ liệu trực tiếp từ API hệ thống nhà trường.

> Phù hợp khi bạn cần xem lịch / điểm nhanh trên điện thoại, đặc biệt lúc cổng đào tạo hoặc app chính không tiện dùng.

## 🤖 Cài đặt Android

1. Mở **[thư mục tải app](https://drive.google.com/drive/folders/19b1QsKBzG7CpCK2fog-W76dGSH0c6qWu?usp=sharing)** và tải file **APK** về điện thoại.
2. Mở file APK vừa tải.
3. Nếu hiện cảnh báo *“Cài đặt ứng dụng từ nguồn không xác định”* → chọn **Cài đặt** / **Cho phép**.
   - Một số máy: **Cài đặt → Bảo mật → Cho phép cài từ nguồn không xác định**.
4. Chờ cài xong → mở app từ màn hình chính.
5. Đăng nhập bằng tài khoản **cổng đào tạo VLUTE**.

## ⚙️ Nguyên lý hoạt động

```text
Đăng nhập VLUTE  →  Gọi API nhà trường  →  Hiển thị trên app  →  Cache cục bộ
```

| Bước | Chi tiết |
|:---|:---|
| **Đăng nhập** | Xác thực trực tiếp với cổng đào tạo VLUTE |
| **Lấy dữ liệu** | Thời khóa biểu, điểm, hồ sơ, học kỳ hiện tại |
| **Cache** | Lưu trên thiết bị để mở lại nhanh hơn |
| **Giao diện** | React Native + Expo — trải nghiệm đồng nhất Android & iOS |
