Tải xuống

Một thư mục — đủ Android & iOS

Lấy bản cài đặt chính thức từ Google Drive, rồi làm theo hướng dẫn từng nền tảng.

Mở thư mục tải app

Android

  1. Tải file .apk từ Drive.
  2. Cho phép cài từ nguồn không xác định nếu được hỏi.
  3. Mở app và đăng nhập tài khoản VLUTE.

iOS

  1. Tải file iOS từ Drive.
  2. Chọn 1 phương án ở hướng dẫn iOS rồi làm đúng bước.
  3. Mở app và đăng nhập tài khoản VLUTE.

iOS · Cập nhật 2026

Cài IPA trên iPhone

Lifetimeetime cert / auto-renew — chọn 1 phương án, làm đúng từng bước.

Chỉ tham khảo kỹ thuật. Tự bảo đảm quyền dùng IPA. Cert bên thứ ba có thể bị thu hồi bất cứ lúc nào.

Cảnh báo: Dùng Apple ID / iCloud phụ (tài khoản phụ). Không dùng tài khoản chính — tránh khóa máy, mất dữ liệu iCloud, hoặc rủi ro bảo mật khi sideload / nhập Apple ID vào AltStore · SideStore · công cụ ký.

Phương án Máy tính Cert Hiệu lực
TrollStore Lần đầu Không Vĩnh viễn
ESign Không Cần .p12 Theo cert
AltStore Chạy nền Apple ID 7 ngày
SideStore Lần đầu Apple ID 7 ngày

iOS ≤ 17.0 → ưu tiên TrollStore. Không máy tính → ESign. Muốn ổn định + có PC → AltStore.

Lifetime

1. TrollStore

iOS 14.0b2–16.6.1 · 16.7 RC · 17.0 — không hỗ trợ 16.7.x / ≥17.0.1

GitHub Guide
  1. Bước 1: Máy tính tải TrollRestore (Win/Mac).
  2. Bước 2: iPhone tắt Find My · App Store cài app Tips.
  3. Bước 3: Cắm USB → mở TrollRestore → target gõ Tips → chạy.
  4. Bước 4: Máy reboot → mở Tips → bấm Install TrollStore.
  5. Bước 5: TrollStore → Settings → Install Persistence Helper → chọn Tips.
  6. Bước 6: Mở IPA trong TrollStore → bấm + → cài xong.
Cert

2. ESign / 易能签

iOS 16+ · không cần PC · bắt buộc có .p12 + .mobileprovision

enqapp.com
  1. Bước 1: Safari mở enqapp.com → cài ESign.
  2. Bước 2: Cài đặt → Cài đặt chung → VPN & Quản lý thiết bị → Tin cậy.
  3. Bước 3: ESign → nhập .p12 + .mobileprovision → gõ mật khẩu cert.
  4. Bước 4: Import IPA → chọn cert → bấm Signature.
  5. Bước 5: Bấm Install → vào VPN & Quản lý thiết bị → Tin cậy lại.
Auto renew

3. AltStore

Apple ID miễn phí · 7 ngày · PC phải chạy AltServer + cùng WiFi

altstore.io
  1. Bước 1: PC tải AltServer từ altstore.io (Win: cài iTunes bản Apple, không dùng Store).
  2. Bước 2: Cắm USB → AltServer → Install AltStore → nhập Apple ID phụ (không dùng ID chính).
  3. Bước 3: iPhone: Cài đặt → Cài đặt chung → VPN & Quản lý thiết bị → Tin cậy.
  4. Bước 4: AltStore → Settings → Refresh Apps → chọn Always.
  5. Bước 5: PC AltServer → bật Enable WiFi Sync.
  6. Bước 6: Gửi IPA vào iPhone → Share → AltStore → cài.
Auto renew

4. SideStore

iOS 15–18+ · lần đầu cần PC · sau đó renew qua LocalDevVPN

docs.sidestore.io Cài đặt
  1. Bước 1: PC dùng iloader cài SideStore lên iPhone (theo docs).
  2. Bước 2: iPhone: VPN & Quản lý thiết bị → Tin cậy.
  3. Bước 3: Mở LocalDevVPN → bấm Connect.
  4. Bước 4: SideStore → đăng nhập Apple ID phụ → My Apps → bấm 7 DAYS để refresh.
  5. Bước 5: Giữ LocalDevVPN Connected → SideStore tự renew nền.
